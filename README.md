# 📖 About

**Legacy XI** is a premium **offline-first cricket scoring application** built specifically for local cricket, street cricket, box cricket, turf cricket, and college tournaments.

Unlike traditional scorekeeping apps, Legacy XI doesn't just record matches—it builds **a permanent cricket legacy**.

Every completed match automatically updates player careers, team histories, records, achievements, and detailed statistics, allowing users to relive every memorable performance long after the match has ended.

The app is inspired by the smooth scoring workflow of modern cricket scoring applications while introducing a richer player-centric analytics system and a carefully crafted, premium user experience.

## 🧠 Team-wise Player Analytics

A unique feature of Legacy XI.

Every player's performance is tracked separately for every team they represent.

Example:

```
Player

Prajwal

Career

Matches : 52

Runs : 1827

Average : 44.8

↓

Teams Played

Royal Tigers

Runs : 724

Matches : 18

Average : 48.2

↓

Phoenix XI

Runs : 618

Matches : 16

Average : 41.3
```

This allows players to compare performances across different teams.
